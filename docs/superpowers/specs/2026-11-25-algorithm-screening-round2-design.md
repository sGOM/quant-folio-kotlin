# 논문 알고리즘 선별 2라운드 — 밸류·잔차 모멘텀·최소분산

1라운드 설계: [`2026-11-24-algorithm-screening-design.md`](2026-11-24-algorithm-screening-design.md). 이 문서는 바뀐 점만 적는다 —
적지 않은 것(구간·유니버스·체결·비용·스냅샷·교정 방식·결측 처리·산출물 위치)은 1라운드와 같다.

## 왜

1라운드 후보(A1~A5)는 잠정 전부 불합격이었다. 웹 조사(국내 재현 연구 Kang 2020: 밸류 69%·모멘텀 67% 재현, 수익성 5%)로
권위 있고 우리 데이터로 시험 가능한 후보 셋을 골랐다. 목적은 같다 — H1 기준 전략을 학습 구간에서 **실제로** 개선하는 것만 적용.

## 후보 (2026-11-25 사용자 결정: 거르지 않고 셋 다 시험)

| ID | 후보 | 정의 | 근거 | 적용 비용 |
|---|---|---|---|---|
| B1 | 밸류 | **Kotlin `value` 그대로** — PER(>0 만)·PBR 역방향 z, 배당수익률 z 의 평균. 입력은 `Valuation` 정의(아래) | [Kang 2020](https://www.emerald.com/jdqs/article/28/2/3/206237/Market-anomalies-in-the-Korean-stock-market), Fama-French 계열 | 통과 시 설정만 |
| B2 | 잔차 모멘텀 | **Kotlin `ResidualMomentum` 그대로** — KOSPI200(1028) 월수익률에 36개월 회귀(관측 ≥ 24), 직전 1개월 제외 11개월 잔차 평균/표준편차 | [Blitz, Huij & Martens 2011](https://ideas.repec.org/a/eee/empfin/v18y2011i3p506-521.html) | 통과 시 설정만 |
| B3 | 수축 공분산 최소분산 비중 | 선택은 그대로(상위 20), **비중만** 롱온리 최소분산. 공분산 = Ledoit-Wolf 수축 | [Ledoit & Wolf 2004](https://bse.eu/research/working-papers/honey-i-shrunk-sample-covariance-matrix) | 통과 시 Kotlin 비중 옵션 신규 |

**B1 입력 = Kotlin `Valuation`** (2026-11-25 사용자 결정: Kotlin 정의 + 배당 적재):
- PER = 시총 / 지배주주 순이익, PBR = 시총 / 지배주주 자본. 적자·자본잠식은 null. 재무는 **접수일 ≤ 결정일**인 최신 사업보고서(연결 우선, 별도 폴백) —
  1라운드 quality 의 `lagged_year` 규칙과 다르다(Kotlin 안에서도 두 경로가 다르다 — 원본 보존, 고치지 않는다).
- 배당수익률(%) = 최근 365일 주당 현금배당 합 / 종가 × 100, 단위는 `PriceUnits`(배당락일 비 ÷ 결정일 비). 전체 적재 후 배당 없음은 0.0.
- 시총·종가 = 결정일 이하 최신 스냅샷 행.

**B3 정의 (내가 정한 값):** 결정일까지 252거래일 일수익률(종목별 유효 ≥ 200, 하나라도 미달이면 그 결정일은 동일가중으로 두고 횟수를 보고),
`sklearn.covariance.LedoitWolf`(항등 목표 — 설치된 의존성, 위 논문과 같은 저자의 수축 추정량), 롱온리·종목당 상한 10%·합 1, `scipy` SLSQP.
ponytail: 상수상관 목표(“Honey” 논문)가 아니라 항등 목표 — 결과가 경계선이면 상수상관으로 재확인.

## 데이터 선행 작업

1. **배당 적재:** qf-paper `dividends` 테이블이 비어 있다. data.go.kr 배당 V2 전체 이력을 **한 번** 받는다(약 7만 행, 개발계정 일 10,000 호출 중 수 호출).
   worker 에 수동 1회 실행 트리거가 없으므로(주간 스케줄만) `BackfillRunner` 처럼 속성으로 켜는 1회 실행을 추가한다. 실패 시 재시도 반복 금지.
2. **DART 백필 완료**(진행 중) — B1(PER·PBR)과 기준 H1 quality 가 같이 기다린다.
3. **스냅샷 확장:** 가격·시총 시작을 2014-01 로 당긴다(B2 의 36개월 회귀, B3 의 252일). KOSPI200(1028) 지수 종가, 배당, DART `rcept_dt` 를 추가한다.
   DB 에는 종목 가격·1001·1028 모두 2014-01-02 부터 있다(2026-11-25 확인).

## 단계 (사용자 결정 A)

- **지금(잠정):** 코드·테스트 전부. 가격만 쓰는 B2·B3 를 lowvol 기준으로 잠정 실행(`passed` 는 None).
- **DART 적재 후(최종):** 새 스냅샷 하나, H1 교정 한 번으로 **1라운드 2단계(A1~A5, 1라운드 규칙)와 2라운드(B1~B3, 아래 규칙)를 같이** 돌린다.
  두 묶음은 다중검정·PBO 를 따로 센다.

## 변형 (주 변형 = 첫째, 나머지는 이웃)

| | 주 | 이웃 |
|---|---|---|
| B1 | value .2 | .1, .3 |
| B2 | residual_momentum .2 | .1, .3 |
| B3 | 252일·상한 10% | 126일, 504일 (상한 10%) |

가중치 변형은 1라운드와 같은 `reweight`(기존 가중치를 1−w 로 축소).

## 시험 항목 — 1라운드와 다른 것만

결과를 보기 전에 고정한다(2026-11-25, 1라운드 설계의 "다음 라운드 후보"를 사용자가 이의 없이 채택).

- **항목 3:** 짝지은 부트스트랩 P ≥ 0.8 → **Ledoit-Wolf Sharpe 차 검정**(일간, 변형−기준, 양측 p)을 B1~B3 주 변형 3개에 대해 **Holm 보정, p < 0.05**. 견고성 항목 그대로(5개 중 하나).
- **항목 7 (B1·B2):** IC 95% 구간이 기대 방향으로 0 을 벗어남 **그리고** Fama-MacBeth 기울기 NW t > 3.0(Harvey, Liu & Zhu 2016). 방향은 둘 다 +. 신호는 B1 = 카테고리 점수(PER·PBR·DIV z 평균), B2 = `resid_mom`. B3 는 신호가 없어 해당 없음.
- **항목 8:** B1·B2 = 위약(해당 카테고리 입력을 유니버스 안에서 종목째 섞기, 200회, Δ > 위약 95분위). B1 은 PER·PBR·DIV 를 **한 종목 묶음으로** 섞는다.
  B3 = 무작위 비중 위약(같은 선택 위에 상한 10% 를 지키는 무작위 롱온리 비중 200회, Δ > 95분위) — "최소분산이 아니라 아무 비중이나 바꿔도 나오는 차이"를 배제.
- **PBO:** 기준 + 2라운드 변형 9개, < 0.5(필수).
- **SPA:** 보조 보고만. 주 변형을 미리 정해 "여러 변형 중 최고 고르기"를 하지 않으므로 판정 규칙의 SPA 조건은 해당 없음.
- 그 밖(항목 1·2·4·5·6, 필수/견고성 3/5 구조)은 1라운드와 같다. 보조 보고(`screen_eval`)도 같이 낸다.

## 교정 (Kotlin 일치)

1라운드는 기준 설정만 교정했다. 2라운드는 B1·B2 가 Kotlin 설정만으로 적용되므로 **H1, H1+B1 주 변형, H1+B2 주 변형** 세 설정을
Kotlin 백테스트와 대조한다(월 수익률 상관 ≥ 0.95, 보유 겹침 ≥ 80%, 교정 전용 전략 38 — 시작 금지). 하나라도 미달이면 그 후보는 판정하지 않고 원인을 보고한다.
B3 는 Kotlin 에 없어 교정 대상이 아니다(통과 시 Kotlin 구현 후 같은 기준으로 재현 확인).

## 적용 (통과분만)

- B1·B2: 사용자 확인 후 가설 설정(`factor_weights`)에 반영. 코드 변경 없음.
- B3: Kotlin 비중 옵션(롱온리 최소분산) 신규 + 정답지 + 재현 확인. 별도 계획.
