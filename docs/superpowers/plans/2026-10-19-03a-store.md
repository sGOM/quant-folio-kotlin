> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 외부 소스 실패를 원인별로 표현하는 예외 체계, 로컬 영구 저장소(JdbcTemplate) 6테이블 리포지토리, "4상태" 캐시 진입점.

**Architecture:** 원본 `app/services/data/errors.py`, `store/*`, `loader.py` 의 price_ticks 부분을 `core/market/` 아래로 옮긴다.
pandas DataFrame 대신 **테이블별 타입 행(data class, 숫자는 `Double?`)** 을 주고받는다 — 읽는 쪽이 필요한 컬럼만 고르고, upsert 는
모든 컬럼에 `COALESCE(excluded, 기존)` 를 걸어 "들어온 null 은 기존값 보존" 의미를 유지한다.

**Tech Stack:** NamedParameterJdbcTemplate, Testcontainers.

**Spec:** 설계 §4.1(JdbcTemplate), §6.1, §7

## Global Constraints

- 원인 5종과 속성(원본과 동일): Auth(retryable=false, cooldown 300s) · Quota(false, 300s) · Unavailable(true, 60s) · Schema(false, 없음) · Request(false, 없음). 대표 우선순위 Auth > Quota > Request > Schema > Unavailable. 스키마 체계적 실패 임계 3.
- HTTP 매핑(web): Request → 500 `외부 데이터 소스 요청이 잘못됐습니다.`, Schema → 502 `외부 데이터 소스 응답을 해석할 수 없습니다.`, 그 외 → 503 `외부 데이터 소스를 사용할 수 없습니다.`; 본문에 `source`, `cause`(원본 Python 클래스명: `SourceAuthError` 등), `retryable`.
- 확정 기준: KST 오늘의 **전날까지**만 확정. 0행 결과는 절대 확정으로 굳히지 않는다. 확정 요청이어도 "요청 컬럼 중 전부 null 인 컬럼"이 있으면 확정 보류.
- cache key: 인자를 `|` 로 잇고, 목록형은 정렬 후 `,` 로 잇고, 날짜는 `yyyyMMdd`.
- 종목코드는 저장 시 6자리 0-패딩. 같은 종목 중복은 마지막 값 채택.
- 숫자 저장은 `BigDecimal(double.toString())`(원본 `Decimal(str(v))`), NaN/±Inf/변환불가 → null.
- `dart_financials` 확정 판정은 원본처럼 `date.today()`(컨테이너 UTC) 기준 — **원본 동작 보존**, `docs/migration-notes.md` 에 기록.

## Review Focus

1. **부분 적재 후 다른 소스 적재** — 시총만 있는 행에 펀더멘털 upsert 가 시총을 null 로 덮으면 안 된다. → Task 3 `upsertPreservesExistingWhenIncomingNull`.
2. **스키마 변경으로 컬럼 전체가 null** — 확정으로 굳으면 영구 결측. → Task 2 `allNullColumnNotFinal`.
3. **원격 실패를 빈 결과로 삼킴** — 반드시 예외 전파. → Task 2 `remoteFailurePropagates`.
4. **커버리지 인접 구간 병합** — `[1/1~1/10]`+`[1/11~1/20]` 은 하나로. → Task 3 `coverageMergesAdjacent`.
5. **KST 자정 직후 확정 판정** — UTC 기준이면 과소확정. → Task 2 `lastFinalDateIsKstYesterday`.
