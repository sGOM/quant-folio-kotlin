# 3c단계 기타 외부 소스 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 네이버 일봉(FDR/pykrx 폴백)·price_ticks 보충·유니버스, KOFIA, KIS 종목마스터, OpenDART 재무, 종목 카탈로그를 원본과 같은 요청·후처리로 이전.

**Architecture:** 공용 `ExternalHttp`(JDK HttpClient, 바이트 응답) 뒤에서 소스별 클라이언트가 원인 분류를 한다. 원본 모듈 대응:
`data/loader.py`·`data/ingest.py` → `market/ohlcv/`, `data/kofia.py` → `market/kofia/`, `data/kis_master.py` → `market/kis/`,
`data/opendart.py` → `market/dart/`, `services/symbols.py`·`metrics/names.py` → `market/symbols/`.

**Spec:** 설계 §6.1·§6.2

## Global Constraints

- HTTP 상태 분류는 3a `classifyHttp` 와 같은 규칙: 429 Quota, 401/403 Auth, 그 외 4xx Request, 5xx Unavailable, 연결·타임아웃(IOException) Unavailable. 실패는 `noteFailure`.
- 네이버 차트: `https://fchart.stock.naver.com/sise.nhn?timeframe=day&count=6000&requestType=0&symbol={code}`(FDR), 폴백 `http://fchart.stock.naver.com/sise.nhn?symbol={code}&timeframe=day&count={elapsed}&requestType=0`(pykrx, elapsed = 오늘−시작일+2일). `<item data="yyyyMMdd|O|H|L|C|V" />`.
- price_ticks 시각 = 거래일 00:00 UTC(원본 tz-naive → UTC 부여).
- KOFIA: POST JSON `https://freesis.kofia.or.kr/meta/getMetaDataList.do` `{"dmSearch":{"tmpV40":"1","tmpV41":"1","tmpV45":start,"tmpV46":end,"OBJ_NM":obj}}`, obj 증시자금 `STATSCU0100000060BO`, 신용융자 `STATSCU0100000070BO`. 쿨다운 중이면 Quota.
- KIS 마스터: `https://new.real.download.dws.co.kr/common/master/{kospi_code|kosdaq_code}.mst.zip`, cp949, 고정폭(원본 필드 폭·컬럼명 그대로).
- OpenDART: base `https://opendart.fss.or.kr/api`, `crtfc_key` 는 로그·예외 메시지에서 `***` 로 가린다. status `000` OK, `013` 무자료(null), 매핑 010/011/012 Auth, 014 Request, 020/021 Quota(020 은 자정까지 retryAfter), 100/101 Request, 800/900 Unavailable, 그 외 Unavailable. 키 없으면 모든 조회 null(실패 아님).
- 종목 카탈로그: seed 70종(원본 그대로) + KRX finder + FDR 시총 목록. 외부 소스가 하나도 안 되면 캐시하지 않는다.
- 응답 픽스처에 실제 API 키·쿠키 금지(공개 저장소).
