# 6단계 워커(배치) Implementation Plan

**Goal:** 원본 Celery beat 9개 태스크(`worker/tasks.py`)를 Spring `@Scheduled`(cron, Asia/Seoul)로 이전.
**Spec:** 설계 §4(앱 분리)·§9(운영). 원본 `worker/celery_app.py` 의 스케줄 그대로.

## Global Constraints
- 배치 실패는 반드시 알림으로 사람에게 넘긴다(`AlertPublisher`, dedup 창 원본 값 그대로). 한 단계 실패가 배치 전체를 멈추지 않는다.
- 날짜는 KST(`MarketClock`). 원본 `date.today()`(UTC) 를 쓴 곳은 원본 그대로 보존하고 migration-notes 에 기록.
- 외부 조회·pg_dump·S3 는 테스트에서 fake. 실 네트워크 금지.
