# 5단계 REST·WebSocket API Implementation Plan

**Goal:** 원본 FastAPI 라우트 15개(인증 제외 14개)를 Spring MVC 로 이전해 프론트가 무수정으로 붙게 한다.
**Spec:** 설계 §5(API 계약) · `.claude/rules/api.md`. 계약서는 원본 `frontend/lib/api.ts` + 라우트 파일.

## Global Constraints
- 경로·메서드·쿼리 이름·기본값·범위·상태코드·응답 필드·오류 문구를 원본과 같게. 쿼리 범위 위반은 422 `loc:["query",name]`.
- 인증은 `@CurrentUser`. 사용자 소유 리소스는 남의 것이면 404(존재 노출 금지) — 원본 동작 그대로.
- 무거운 계산 캐시는 원본 Redis 키·TTL 그대로(컷오버 때 캐시가 이어진다). 빈 결과는 캐시하지 않는다.
- 테스트: `@SpringBootTest` + MockMvc + Testcontainers, 외부 조회는 `@MockitoBean`/fake 로 교체(실 KRX 금지).
